# Native platform templates

The `android/` and `ios/` folders are generated by Flutter and are **not**
committed. Generate them once, then apply the production settings below:

```bash
cd app
flutter create . --platforms=android,ios --org com.yourco --project-name stylecheck
```

## iOS (`ios/Runner/`)

1. **Info.plist** — merge in `ios/Info.plist.additions.xml`:
   - `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription` (required by
     `image_picker`, or the app is rejected/crashes)
   - `CFBundleDisplayName` = `StyleCheck`
2. **Privacy Manifest** — copy `ios/PrivacyInfo.xcprivacy` into
   `ios/Runner/PrivacyInfo.xcprivacy` and add it to the Runner target in Xcode.
   Apple requires this at submission.
3. **Deployment target** — set to **15.0** (RevenueCat Paywalls / Customer
   Center). In `ios/Podfile`: `platform :ios, '15.0'`, then `pod install`.
4. Add your `GoogleService-Info.plist` to the Runner target (gitignored).
5. Enable **App Attest** capability for Firebase App Check in release.

## Android (`android/app/`)

1. **AndroidManifest.xml** — merge in `android/AndroidManifest.additions.xml`
   (INTERNET permission, camera feature flag as optional, app label).
2. **build.gradle** (`android/app/build.gradle`):
   - `minSdkVersion 24` (required by `purchases_ui_flutter`)
   - `targetSdkVersion` / `compileSdkVersion` = latest
   - enable `multiDexEnabled true` if needed
   - configure a real release `signingConfig` (keystore, gitignored)
3. Add your `google-services.json` to `android/app/` (gitignored) and the
   Google Services Gradle plugin.
4. Register **Play Integrity** for Firebase App Check.
5. `android/app/proguard-rules.pro` — see `android/proguard-rules.pro`.
